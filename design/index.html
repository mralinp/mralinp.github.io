    Nunya: Building an Honest, Open-Source VPN Client

    28 September 2026 · 9 min read · GitHub repo
    ProjectVPNRustTauri

    Nunya is a desktop VPN client for macOS, Windows and Linux. You give it the servers you already have, and it connects you through them. It's free, it's GPL-3.0, and it has no account and no telemetry.

    1. The idea

    If you live somewhere with a filtered internet, a VPN client isn't a nice-to-have, it's how you reach half the web. Most clients say more than they know: a green "Connected" usually means a process started, not that your traffic gets through.

    Rule: the app never claims more than it can prove.

    2. How it's built

    The app and the engine talk over two tiny frames on a unix socket:

    textrequest   [u32 id][u16 method_len][method][u32 payload_len][protobuf]
response  [u32 id][u8  status    ][u32 payload_len][protobuf or error text]

    Both ends verify each other, so no local process can pretend to be the core and report a healthy tunnel that doesn't exist.

    3. Building it like a real project

    Every merge to main is a release. The PR title decides the version bump, and CI builds for all three platforms.
