      tdsc-abus2023-pytorch: A PyTorch Dataset for 3D Breast Ultrasound

      23 September 2026 · 7 min read · GitHub repo
      ProjectMedical imagingPyTorch
      On this page

      tdsc-abus2023-pytorch is a PyTorch Dataset for the TDSC-ABUS 2023 challenge: 200 automated 3D breast ultrasound volumes, each with a tumor mask, a bounding box and a label.

      1. Why a package at all

      Every project that uses the data ends up writing the same glue: download, unzip, parse the CSVs, read the NRRD volumes.

      Rule: load the data correctly, load it fast, and get out of the way.

      2. A memory-mapped cache

      pythonreturn np.load(npy_path, mmap_mode="r")

      Workers share the OS page cache, so four workers don't mean four copies of a volume in RAM.

      3. Shipping it

      CI bumps the version and publishes to PyPI on every push to main.
